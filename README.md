# 📝 AI Text Summarizer

Paste any text and get a summary in your chosen length and style. Built with Streamlit and the Claude API.

## Run
```bash
pip install -r requirements.txt
echo ANTHROPIC_API_KEY=your_key_here > .env
streamlit run app.py
```

## Features
- Choose summary length (1 sentence, paragraph, bullets)
- Choose style (simple, professional, ELI10)

## Tech
Python · Streamlit · Anthropic API
